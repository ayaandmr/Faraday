# Faraday documentation

Faraday is an age-13+ learning pilot. The Start a Topic vertical slice is real: Clerk authentication, Groq-generated lesson cards, Supabase persistence, visible lesson history, progress, safe memory candidates, resume cards, and lesson suggestions. Tests, the broader progress experience, and several secondary dashboard features remain prototypes.

Read [`architecture.md`](architecture.md), then [`Backend/README.md`](Backend/README.md), [`Backend/api-contracts.md`](Backend/api-contracts.md), and [`Dev/getting-started.md`](Dev/getting-started.md) before working on the learning system.

For the latest implemented behavior and fixes, read [`Dev/2026-10-02-progress.md`](Dev/2026-10-02-progress.md).

When code behavior changes, update its corresponding document in the same change.
