# Faraday

Faraday is an early-stage education platform that helps teachers create AI-assisted lessons and supports each student with a clearer, more personal learning path.

## Development

```powershell
npm.cmd install
npm.cmd run dev
```

Open `http://localhost:3000` in your browser.

## Documentation

Start with [`docs/README.md`](docs/README.md). It explains what is implemented today, what is still mocked, and where to find the frontend, backend, architecture, and developer documentation.
